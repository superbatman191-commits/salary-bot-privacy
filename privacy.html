Privacy policy — salary-bot

Last updated: 6 October 2026

salary-bot is a private Telegram bot for a closed group of truck drivers (up to 100 people). Access is granted manually by its owner and developer; it is not offered to the public.

What data the bot handles

  • Timesheet scans, name, email and messages that drivers send to the bot in Telegram.
  • Working hours and pay amounts read from those scans.

How Google user data is used

  • Gmail (send): to email the weekly result with the scan attached.
  • Gmail (read-only): only to check the owner's Sent folder so the same week is never emailed twice.
  • Google Sheets: to write the weekly result into the owner's own spreadsheet.

Google user data is used only for these functions, is not sold, not shared with third parties, not used for advertising and not used to train AI models. salary-bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other services

Scans are sent to an AI model (Anthropic Claude) only to read the numbers. Each driver's timesheets are stored in a separate folder on the owner's Google Drive; only the owner can see them, drivers see only their own data in the bot. Calculation rules are read from the owner's Notion.

Storage and deletion

Data is stored on the owner's server and in the owner's own accounts. Access tokens are kept locally and never published. A driver can ask the owner to delete their data at any time. To delete data or revoke access, remove it from the accounts above or revoke access at myaccount.google.com/permissions.
